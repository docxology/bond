# Manuscript syntax reference

Markup rules for the compendium's sections. The repository-wide semantics are in
[`docs/guides/manuscript-semantics.md`](../../../../../docs/guides/manuscript-semantics.md);
this file covers what is specific to a **wrapper** manuscript whose chapters are
imported from documents written to render somewhere else.

Most of these rules apply to the three hand-authored sections. The generated
chapters follow them because `build_package_section()` and
`build_architecture_section()` emit them that way.

## Tokens

```markdown
PROJECT BOND is a fleet of **{{N_PACKAGES}} independent software packages** —
**{{N_FILMS}} film packages** plus **{{N_INFRA}} mission-infrastructure packages**.
```

The complete set, from `src/bond_manuscript/manuscript_variables.py::generate_variables()`:

| Token | Value |
| --- | --- |
| `{{SUITE_TITLE}}` | `PROJECT BOND — The Special-Agent Operations Compendium` |
| `{{SUITE_TITLE_SHORT}}` | `PROJECT BOND Compendium` |
| `{{N_PACKAGES}}` | discovered package count |
| `{{N_FILMS}}` | packages with `kind == "film"` |
| `{{N_INFRA}}` | packages with `kind == "infra"` |
| `{{N_GATE_MEASURED}}` | packages with a numeric coverage row in the fleet gate manifest |

Never type one of those counts as a literal. Tokens are resolved into
`output/manuscript/` before rendering; an unresolved one appears verbatim in the
PDF.

## Citations

Keys resolve against the unified `references.bib`, which is generated by merging
every package's bibliography. **Do not add an entry to it** — add it to the source
package's `references.bib` and re-run `scripts/generate_compendium.py`.

```markdown
<!-- how generated chapters cite -->
## Sources

@walras1874elements; @kyle1985continuous
```

Pandoc converts `[@key]` to the correct LaTeX citation command. Never write raw
`\cite{}` in Markdown.

Key shapes reaching the merge:

- keys from real BibTeX entries, preserved as the source package wrote them;
- `<slug>_ref<n>` for entries converted from a plain-text `[n] …` reference list.

## Cross-references are stripped, not resolved

An imported abstract may cite its own package's sections and theorems. Those
labels do not exist here, so `_strip_crossrefs()` removes them before the chapter
is written: `[@sec:results]` becomes readable prose, and `def`, `prop`, `thm`,
`lem`, `cor`, `fig`, `eq`, `tbl`, `lst` references are dropped along with any
parenthetical that introduced them.

So: do not add a package-local cross-reference to any section here — it will not
survive the next build. `test_imported_abstracts_carry_no_dangling_crossrefs`
fails if one does.

## Headings and file order

One `# Title` H1 per file, no section labels. Assembly is lexicographic by
filename:

```text
00_abstract.md             Abstract
01_introduction.md         Introduction
02_suite_architecture.md   Suite Architecture       (generated)
03_01_dr_no.md … 03_27_…   Film chapters            (generated, canon order)
04_01_bond-utilities.md …  Infrastructure chapters  (generated)
90_closing.md              Closing
99_references.md           References               (generated)
```

Generated chapter headers take the form `# <Title> — <CODENAME>`, e.g.
`# Goldfinger (1964) — GRAND SLAM`.

## Math

`$…$` inline, `$$…$$` display. For a referable equation, attach a pandoc-crossref
anchor after the closing `$$`:

```markdown
$$
x_{k+1} = x_k - \alpha \nabla f(x_k)
$$ {#eq:example}
```

Reference it as `[@eq:example]`, never with raw `\ref` or `\eqref`. Note that
equation labels in an *imported* abstract are stripped — the anchor only works in
a hand-authored section.

## Tables

Caption below the table, label inside the caption line:

```markdown
| Layer | Packages |
| --- | --- |
| Layer 0 · utilities | `bond-utilities` |

: Suite layering. {#tbl:layers}
```

Reference as `[@tbl:layers]`. Do not hardcode a table number.

## BibTeX in source packages

```bibtex
@article{kyle1985continuous,
  author  = {Kyle, Albert S.},
  title   = {Continuous Auctions and Insider Trading},
  journal = {Econometrica},
  year    = {1985}
}
```

Minimum `author`, `title`, `year`. Accents may be written as LaTeX commands —
`latex_to_text()` resolves them to Unicode before braces are removed, so
`Poincar\'e` renders as `Poincaré` rather than emitting a control sequence that
kills the Beamer build.

## Preamble

`preamble.md` holds the LaTeX packages injected at compile time. Do not duplicate
a package the infrastructure renderer already includes.

## Prose

Explicit over vague: name the file and the function. Avoid "In summary" and "In
conclusion" as closers. Keep one idea per paragraph.
