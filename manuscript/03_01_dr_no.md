# Dr. No (1962) — CRAB KEY

*film package · mission codename CRAB KEY*. Mission **CRAB KEY**: identify gamma-emitting isotopes from a measured spectrum; model radioactive plume dispersion under local meteorology; assess island-wide radiological threat and containment actions.

## Concepts

radiation/isotope forensics, island threat assessment

## Abstract (imported from the package manuscript)

**Abstract.** Crab Key, a small island held by a shadow syndicate, shelters a radiological threat that must be located, characterised, and contained. This package, codename CRAB KEY, is the special-agent mission software that executes that assessment. It couples three deterministic, computation-first models: a gamma-spectrum isotope-identification engine built on a real emission-line library (10 isotopes, 23 principal lines); a Gaussian-plume atmospheric-dispersion model over the 6 Pasquill–Gifford stability classes (A, B, C, D, E, F); and a Crab Key-style island threat assessor that scores each detected facility from its isotope inventory, containment status, and local meteorology, then recommends a containment action. The mission is exposed through the BOND-API mission protocol (codename CRAB KEY, film Dr. No, version 0.1.0) and is fully deterministic: fixed scenario, fixed seed, no randomness, no wall-clock dependence in any persisted artifact. All figures in this report are generated from the same code that produces the underlying measurements, so the manuscript cannot drift from the software.
